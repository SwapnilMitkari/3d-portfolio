# Swapnil Mitkari — 3D Portfolio

An interactive 3D developer-style portfolio built with React, Three.js (via
react-three-fiber) and Tailwind CSS. Fly around an island, browse real work
history, and get in touch.

## Sections
- **Home** — interactive 3D island/plane/bird scene
- **About** — skills + work experience timeline (RBL Bank, internships)
- **Projects** — Micro-Confidence, Siemens supplier-onboarding n8n automation,
  PoshanSetu, industrial-automation research, published research article,
  a GTM concept rap, and two product-management case studies
- **Contact** — direct contact details + a working contact form (via EmailJS)

## Run locally

```bash
npm install
npm run dev
```

## Set up the contact form (optional)

Copy `.env.example` to `.env` and fill in your own free EmailJS credentials
from [emailjs.com](https://www.emailjs.com/) — the form won't send email
without this.

## Deploy

Push to GitHub, then import the repo on [Vercel](https://vercel.com) or
[Netlify](https://netlify.com) — no config needed, it's a standard Vite app.
